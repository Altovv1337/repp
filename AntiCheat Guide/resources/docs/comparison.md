# Сравнение подходов к защите

Обобщённое, упрощённое сравнение популярных типов античит-решений
(общедоступная информация, без технических деталей обхода).

| Тип защиты      | Уровень доступа       | Плюсы                              | Минусы                                  |
|------------------|------------------------|-------------------------------------|-------------------------------------------|
| Client-side      | Пользовательский режим | Лёгкая интеграция, быстрый отклик   | Проще всего обойти                        |
| Kernel-level      | Драйвер ОС             | Высокая видимость системы           | Вопросы приватности, риски стабильности   |
| Server-side       | Только сервер          | Сложно обойти напрямую              | Требует накопления данных, задержка       |
| ML / эвристика    | Сервер + клиент        | Ловит новые схемы                   | Возможны ложные срабатывания              |

## Общий вывод

На практике большинство современных игр используют **гибридный подход**:
лёгкая клиентская проверка + серверная валидация + поведенческий анализ.
Ни один изолированный метод не считается универсальным решением — важна
совокупность мер и постоянное обновление моделей обнаружения.
